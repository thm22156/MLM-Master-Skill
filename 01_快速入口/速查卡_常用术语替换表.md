# 速查卡：常用术语替换表

| 非马列毛术语（来源） | 替换为 | 替换条件 |
|------|------|------|
| 三问法（赵皓阳） | 阶级分析三段法 | 锚定为列宁阶级分析+毛泽东矛盾分析 |
| 斩杀线（赵皓阳） | 资本剥削的生存底线 | 锚定为马克思剩余价值理论 |
| 创造者（嬴月咏） | 劳动者 | 原概念混淆不同阶级 |
| 转嫁者/索取者（嬴月咏） | 剥削者 | 锚定为阶级分析 |
| 成本转嫁术（嬴月咏） | 剥削的意识形态遮蔽机制 | 锚定为马克思商品拜物教+意识形态批判 |

| 利益集团（阶级内部的） | 阶级内部的派别/集团 | 如垄断资产阶级vs民族资产阶级 |

| 政治正确批判（赵皓阳） | 意识形态领域的阶级斗争 | 锚定为列宁两个思想体系+毛泽东意识形态斗争 |
| Q-R-S-Z-T框架 | **统一为马列毛阶级分析术语** | 删除非马列来源概念 |

## 替换原则

1. 所有替换必须以马列毛原著为依据
2. 替换后不得改变原论证的正确方向
3. 可追溯性由50-03_改造操作手册集中维护
