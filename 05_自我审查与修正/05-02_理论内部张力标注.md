# 05-02_理论内部张力标注

继承自原系列五BOUNDARIES.md。以下张力不代表错误——是马列毛主义理论内部的开放问题，需继续研究：

1. **国家消亡与无产阶级专政**——在阶级消灭前专政必须加强，但专政本身也是"正在消亡的半国家"——二者之间的辩证关系
2. **生产力决定论与革命能动性**——生产关系一定要适合生产力（马克思）vs"政治同经济相比不能不占首位"（列宁）
3. **价值规律在社会主义条件下的作用**——商品制度和货币交换的存在与限制资产阶级法权的要求之间的张力
4. **毛泽东对斯大林批判的未完成性**——对苏联模式的批判方向明确但具体分析尚未充分展开
